用之前先看三条
  1. 先打开答题页（/tree/f/<id> 或 /tree/<loc>/visit?id=<id>），再点书签 —— 书签只在当前页面里执行。
  2. 拖不动就点「复制代码」→ 书签管理器新建书签 → 名称随意 → URL 粘贴整行（必须以 javascript: 开头）。
  3. 别把代码粘进地址栏：浏览器会吃掉 javascript: 前缀。要临时试一次就用 F12 → Console 粘贴。
